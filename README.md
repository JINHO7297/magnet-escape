# 마그넷 스케이터

자석 보드로 달리며 **직접 길을 연결해 옥상 스케이트 축제를 여는** 2D 자동 전진 액션입니다. 한국어·큰 전체 화면·Unity2022.3.62f1을 사용합니다.

## 두 가지 모드

**축제 코스:** 입문·일반·도전 각각4구간, 총12코스. 골목→옥상→공중 레일→스카이라인으로 친구 민의 짧은 연락이 이어집니다. 99곳에서 선택 경로를 만납니다. 회전 광고판 23곳, 천장 케이블 20곳, 차량 18곳, 연쇄 전광판 18곳, 임시 연결로 20곳입니다. 기본 지형으로도 진행할 수 있습니다.

**무한 기록 질주:** 8종의 32m 구간을 섞어 이어 붙입니다. 처음 세 구간에서 별과 기본 시설을 만납니다. 같은 구간은 연속해서 나오지 않으며, 앞쪽 구간을 생성하고 지나온 구간을 정리합니다. 첫 충돌이나 낙사로 종료하며 거리·별·시설 기술로 이 기기의 상위 5개 기록에 도전합니다.

| 조작 | 동작 |
| --- | --- |
| 기본 이동 | 항상 오른쪽 자동 전진. 좌우 입력으로 멈추거나 후진하지 않음 |
| Space | 길게 누르면 높은 점프. 레일에서는 도약 |
| Shift | 전방 대시·쿨다운. 장애물 무적 없음 |
| Q/E | 공중 수직 인력/척력. 레일은 Q로 붙잡고 E/Space로 도약 |
| 회전 광고판 | 접근 중 Q를 유지해 기울기를 올립니다. E로 낮은 다리를 펼칩니다. |
| 천장 케이블 | Space로 뛰고 Q로 케이블에 붙습니다. E나 Q 해제로 아래에 착지합니다. |
| 축제 차량 | Space로 첫 지붕에 오른 뒤 앞 차량으로 건너갑니다. |
| 연쇄 전광판 | 접근 중 E로 열고 Space와 Q로 이어진 조각을 탑니다. |
| Backspace | 고정 코스 CP 재도전: 충돌+1, 시간 유지. 무한에서는 종료 |
| R / Esc | 현재 모드 새로 시작 / 정지·재개 |
| 선택 화면 ←/→, 1~4 | 난이도 변경, 해당 페이지의 코스 시작 |
| 선택 화면 N / B | 무한 질주 / 무한 순위표 |
| H/T/C/M/F11 | 도움말/고정 기록/제작 정보/음소거/전체 화면 전환 |
| 정지 중 Enter/Tab | 재개/선택 화면 |

광고판과 전광판 조작 범위는 시작점 10m 전부터 1m 전까지입니다. 기본 자력은 수직에 작용하고, 레일 탑승 중에는 전진 속도가 35% 빨라집니다. 시설 이용 중에도 장애물과 충돌하면 사망합니다.

## 코스와 점수

| 난이도 | 코스 ID | 길이 |
| --- | --- | --- |
| 입문 | 5~8 | 202 / 236 / 271 / 309 |
| 일반 | 1~4 | 248 / 320 / 380 / 480 |
| 도전 | 9~12 | 344 / 381 / 420 / 464 |

일반의 기존 지형/GUID를 유지했습니다. 입문은 넓은 착지·짧은 틈, 도전은 긴 틈·상하 자석·드론을 조합합니다. 난이도 안에서4번째 코스를 끝내면 축제가 열리고 선택 화면으로 돌아갑니다. 코스별 S기준은 메뉴/데이터에서 확인합니다.

고정 코스 S는 기준 이내 무사망, A는1.5배·2회 이하, B는2배·5회 이하입니다. 기록은 확장 축제 규칙의 `MagnetSkater.v3.Stage`에 저장합니다. 이전v2·짧은 러너·수동 조작 기록은 삭제하거나 합치지 않습니다.

무한 점수는 거리 1m당 10점, 별 50점부터 최대 140점, 시설 기술 성공당 180~320점입니다. 서로 다른 시설을 8초 안에 연속 성공하면 100점을 추가로 받습니다. 이 방식의 로컬 순위는 `MagnetSkater.Endless.v2.Top5`에 저장하며 기존 v1 기록도 보존합니다. 세부 동작과 점수 조건은 [도시 파쿠르 상세 설계](docs/superpowers/specs/2026-11-19-city-parkour-design.md)를 참고하세요.

## 실행과 편집

```bash
git clone --branch develop https://github.com/JINHO7297/magnet-escape.git
```

Unity Hub2022.3.62f1로 프로젝트를 엽니다. Apple Silicon의2022 Package Manager에는 Rosetta2가 필요했습니다. StageSelect 씬에서 시작하고 Game뷰를 클릭합니다. 레거시 Input Manager(Old 또는Both)를 사용합니다.

Resources/Stages/Stage1~12.asset이 원본 배치입니다. Routes에는 Start/UpperEnd/LowerEnd/Label/Facility, 이야기에는 OpeningMessage/EndingMessage를 지정합니다. 기존 씬/프리팹/.meta GUID를 유지합니다. 새 편집 리비전 생성 도구는 원본을 덮어쓰지 않습니다. 무한 모드는 Endless 씬/데이터와 EndlessCourse의 안전 템플릿으로 분리됩니다.

```bash
python3 Tools/validate_project.py
python3 -m unittest discover -s Tools/tests -v
python3 Tools/unity_tasks.py test
python3 Tools/unity_tasks.py build-mac --package
```

Python 검사는 Unity 동작 검증과 다릅니다. Unity 테스트 종료 후 Python 에셋 복사 검사를 실행합니다. 빌드는 앱·한글 안내·크레딧 ZIP을 생성하고 Library/Temp/Logs/Builds/artifacts는 Git에서 제외합니다. 실제 실행본 경로·검사 결과·미검증 범위는 SUBMISSION.md/PROGRESS.md를 확인하세요. 이전53건과4코스 검수는 과거 이력이며12코스/무한 모드의 검수를 대신하지 않습니다.

최신 검수: Unity EditMode20+PlayMode38=58건, Python21건 통과. 고정12코스 자동 무사망 완주와93개CP의 부활 후1초 준비 거리를 확인했습니다. 실제 실행본 키 입력으로 Q상층 탑승/E다리 우회·축제 메시지·난이도 선택, 무한 별2개/570점/사망1회 종료와 앱 재실행 후 순위 보존을 확인했습니다. 사람의12코스 직접 완주/체감·장시간 무한 플레이/다른 Mac은 추가 검수 대상입니다.
