# 축제 경로 제작과 난이도 코스 실행 계획

> Inline execution: superpowers:executing-plans. 사용자 승인한 스토리·경로 제작·난이도 추가를 현재 develop에서 구현한다.

**Goal:** 축제 개막을 위해 도시 코스를 연결하는 신입 스케이터. 입문/일반/도전 각4개, 총12개. 기존1~4/GUID/기록은 보존한다.
**Architecture:** StageInfo의 총 코스/난이도/챕터 매핑을 공통 사용. StageDefinition에 이야기/RoutePlacements, RouteShaper는 Q 상층 그라인드/E 저층 실제 다리를 선택 구간 앞에서만 구성한다. 기본 경로는 항상 남겨 정지 퍼즐·필수 대기·막다른 길을 만들지 않는다.
**Tech Stack:** Unity2022.3.62f1, 기존 Input/PlayerMotor/MagneticRail, C#.

- [ ] 1. RouteShaper 회귀 먼저 작성·실패 확인, 선택/실제 충돌체·레일·상태 차단·자기 위치 안전 검사 구현. source 코스 자석 힘과 신규 구조물 입력을 분리한다.
- [ ] 2. 총12개 카탈로그·난이도별 선택/기록·챕터 전환·짧은 이야기. 기존 코스1~4 배치는 유지하고 새5~8입문,9~12도전. 새 코스에 다수의 선택 경로/체크포인트 배치. 기존v2 보존하고 축제v3 기록 분리.
- [ ] 3. 원본 생성/편집/빌드 도구와 정적 검사 범위 갱신, Unity 전체 및12코스 자동 경로/장치 사용 물리 검수. Mac Universal 빌드·실제 새 선택/스토리/장치 화면 검수. TASKS/PROGRESS/README 기록·단위 커밋·승인된 develop 푸시.

Ruling: 신규 요청은 이전 고정4코스 범위를 확장한다. 강제 기획 승인 질문 없이 위 구체안으로 진행. 추가8코스는 같은 좌표의 단순 난이도 복사 대신 별도 길이/틈/장애물/장치 조합을 가진다. 기존4코스의 기본 경로는 유지하며 이야기/기록 namespace만 갱신한다. 사람의12코스 완주와 자동 검수는 구분한다.

사용자 후속 확장: 별도의 무작위 무한 모드를 추가한다. 고정12코스는 유지. N/선택 버튼으로 진입, 32unit 안전 템플릿을 독립 seed로 무작위 조합·앞100unit 생성/뒤64unit 정리. 거리10점/unit, 별 수집50+연속 보너스, 첫 구조물 제작250점. 낙사/접촉 시1회 종료, 같은 기기의 상위5개 기록을 별도키에 저장한다. 온라인 서버 순위라고 표시하지 않는다. 고정코스와 부활/기록/결승을 분리한다. 무한 진행이 목표인 모드에 한해 이전 무한맵 제외를 해제한다.
- [ ] 4. 무한 모드 충돌 종료·점수/수집·seed 재현·청크 정리·로컬 상위5개 저장 회귀 후 구현, 빌드/화면 확인.
