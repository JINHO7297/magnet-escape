# Magnet Skater 전환 설계

사용자가 선택한 신규 기획: 자석 보드 스케이터가 도심 골목→옥상→공중 레일→스카이라인의 고정 4코스를 자동 전진하며 완주한다. 전투·퍼즐·발전소·폐공장 스토리는 제외한다.

## 확정 동작
- 유효 플레이 중 오른쪽 자동 전진. A/D/방향키로 정지·후진하지 않는다.
- Space 가변 높이 점프, Shift 짧은 전방 대시와 쿨다운.
- Q/E 인력/척력은 공중 수직 궤적을 조절한다. 수평 속도를 역전하지 않는다.
- 장애물 접촉·낙사는 사망 1회, 체크포인트 빠른 부활. 정지/사망/결과/씬 전환 중 전진 정지.
- 4개 유한 코스·기록·랭크·선택·전환은 기존 구조를 활용한다.

## 구현 선택과 범위
기존 Unity 2022.3.62f1/C# 프로젝트를 전환한다. 새 프로젝트로 재작성하면 씬/GUID/기록 도구를 불필요하게 중복하므로 기존 코드를 수정한다. 사용자의 앞선 자동 실행·개발 브랜치 커밋/푸시 승인을 유지한다. 저장소/네임스페이스/에셋 경로는 GUID 호환을 위해 MagnetEscape를 유지하고 화면 제목은 Magnet Skater로 바꾼다.

작성자 결정: 기본 자동 전진 7, 전방 대시 19 등 기존 수치를 초기값으로 사용한다. 기본 4코스는 정지 대기가 없는 수평 진행 배치로 새로 구성한다. 구체적 난이도는 Unity 완주 전 미검증이다. 원본 코스는 Git 이력으로 보존하고 기존 편집본은 덮어쓰지 않는다. 러너 기록은 기존 수동 조작 기록과 별도 키를 사용한다.

## 검증 제약
사용자가 Unity 검수를 미루고 구현을 계속하도록 명시했다. Unity 테스트는 먼저 작성하되 Editor가 없어 RED/GREEN 실행을 주장하지 않는다. Python 회귀·에셋 무결성·C# 구문 검사는 실제 실행하고 결과를 기록한다. 전체 완료는 실제 4코스 검수 전 선언하지 않는다.
